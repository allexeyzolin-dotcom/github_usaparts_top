# Avto.pro → USAparts.top

Один контейнер Chromium/Playwright перевіряє продажі акаунта й передає нові замовлення до USAparts.top. Типовий інтервал становить 300 секунд. n8n і доступ до PostgreSQL сервісу не потрібні.

## Запуск у Portainer

1. Оновіть стек USAparts.top до цієї ревізії. На Docker Standalone створіть стек `usaparts-avtopro` з Git-репозиторію сайту, гілки `refs/heads/main` і файлу `docker-compose.avtopro.yml`. Залиште керування тільки адміністраторам. Окремий домен, публічні порти й Nginx Proxy Manager для цього стека не потрібні. [Розгортання у Portainer](https://docs.portainer.io/user/docker/stacks/add)
2. У [кабінеті USAparts.top](https://usaparts.top/admin/marketplaces/avtopro-orders) виберіть **Серверне підключення → Створити ключ сервісу**. Ключ показується один раз. Ключ Chrome використовується окремо.
3. У Portainer відкрийте контейнер `avtopro-browser`, виберіть **Console → Connect** з командою `/bin/bash`. Виконайте `python configure.py` і один раз введіть email, пароль Avto.pro та ключ сервісу. Пароль і ключ приховано під час введення. Вони записуються у файл з правами `0600` усередині приватного тому контейнера. Зберігайте том і його резервні копії як секрети.
4. `curl -fsS http://127.0.0.1:8090/status` показує результат пробної перевірки. Вона перевіряє вхід і читання без запису на сайт. Після перевірки виконайте `python configure.py --mode sync`. Для повторної проби або паузи доступні `--mode preview` і `--mode paused`. Після зміни пароля знову виконайте `python configure.py`.
5. Звірте перше реальне нове замовлення у «Замовлення / Видача», зміну кількості в каталозі й відсутність повторного списання після наступного циклу. Наявний ключ працює лише на сайті, де його створено. Для перевірки зі стендом вкажіть його HTTPS-адресу у `USAPARTS_ORIGIN` і використайте ключ стенда.

Профіль, режим і файл із секретами зберігаються в томі `browser-profile`. `AVTOPRO_INTERVAL_SECONDS` задає паузу між циклами, `AVTOPRO_BATCH_SIZE` — розмір кожної порції. Один контейнер має ліміти 0,85 CPU, 1200 МБ RAM і 256 процесів. Docker зберігає до трьох журналів по 5 МБ. Chromium працює з пісочницею й окремим профілем seccomp. [Профіль Playwright](https://github.com/microsoft/playwright/blob/v1.64.1/utils/docker/seccomp_profile.json)

## Перевхід і залишки

- Після завершення сесії сервіс використовує штатну форму входу Avto.pro. Після успішного входу опитування відновлюється автоматично. Відмова входу, CAPTCHA або одноразовий код ставлять інтеграцію на паузу й фіксують причину. Пункт 10.4 умов Avto.pro обмежує автоматизований збір даних. [Умови Avto.pro](https://avto.pro/static/regulations/)
- Перший імпорт обмежено новими продажами. Для відомих відкритих карток перевіряються статус і ТТН за номером. Зчитування карток використовує лише методи читання. Єдиний окремий запит на запис під час роботи браузера — штатна авторизація.
- При першому автоматичному імпорті сайт списує кількість із доступного залишку через штатний резерв, атомарно зберігаючи замовлення. Позиції зіставляються за артикулом і, якщо він є, брендом. Якщо позиція неоднозначна або її бракує, жодна позиція цього замовлення не списується й картка отримує позначку для звірки. Відкритий нерезервований автоімпорт можна повторно обробити після усунення причини.
- Раніше імпортовані картки залишаються зі своїм поточним обліком. Повторна доставка того самого замовлення й передача вже врахованого замовлення на пакування не дублюють списання. Підтверджене скасування до відправлення звільняє резерв один раз. Після відправлення повернення звіряє оператор.
- ТТН Нової пошти з системного запису Avto.pro заповнює порожнє поле картки USAparts.top. Різні номери залишаються видимими для звірки.

Сценарій звичайного перевходу, зупинки на додатковій перевірці, списання й повернення залишку покритий тестами. Реальний серверний вхід та перший живий імпорт підтверджуються після одноразового налаштування.
