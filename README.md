# USA AUTO PARTS

Сайт складу та вітрини USA AUTO PARTS.

## Portainer

Основна інструкція запуску:

- `PORTAINER_DEPLOY.md`

Для Portainer рекомендовано використовувати:

- `docker-compose.vps.yml`, якщо Portainer має доступ до репозиторію і може зібрати образ;
- `stack.yml`, якщо образ `usa-auto-parts-site:vps-latest` вже зібраний або завантажений у Docker registry.

## Дані, які не зберігаються в Git

- `app/uploads/` — фото та завантаження;
- `backups/` — архіви сайту;
- `rclone/` — конфіг Google Drive;
- `.env` — приватні паролі та ключі.

## Моніторинг замовлень Нової пошти

Під час звичайного запуску `python -m app.app` окремий фоновий працівник перевіряє ТТН активних замовлень кожні 5 хвилин, пакетами до 100 номерів. Він використовує чинні налаштування НП та працює без відкритого браузера. Історія перевірок зберігається у таблиці `order_tracking`, яка створюється під час запуску.

Сторінка «Замовлення / Видача» отримує збережені статуси кожні 30 секунд, зберігаючи введені дані у формах. Помилки НП повторюються автоматично; час перевірки показано за Києвом. Нова ТТН запускає відстеження заново. Автоматична й ручна перевірки змінюють лише стан доставки: завершення замовлення та списання залишків виконується окремою дією оператора.
