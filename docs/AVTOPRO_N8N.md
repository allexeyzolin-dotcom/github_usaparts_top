# Замовлення Автопро через n8n

Автопро надсилає [поштові повідомлення](https://avtopro.ua/helpcenter/kis/) про нове замовлення, оплату й скасування. Сценарій передає їх до приватного журналу USAparts.top. Якщо в новому листі є один явно підписаний номер, сайт створює картку «Потребує звірки» в «Замовлення / Видача». Повторні листи з тим самим номером прив’язуються до однієї картки. Менеджер додає позиції після звірки з Автопро і використовує звичайний процес видачі.

## Запуск

Розгорніть `docker-compose.n8n.yml` окремим стеком `usaparts-n8n`. Том `n8n_data` містить сценарії, налаштування та ключ шифрування. Редактор доступний з VPS за адресою `http://localhost:5678`. Для віддаленого керування використовуйте наявний доступ SSH і тунель `ssh -N -L 5678:127.0.0.1:5678 КОРИСТУВАЧ@VPS`, потім відкрийте `http://localhost:5678`. Якщо на комп’ютері порт 5678 зайнятий тестовим n8n, зупиніть тестовий контейнер перед відкриттям тунелю.

## Підключення

1. У пошті виділіть папку `Avtopro Orders` і спрямовуйте туди підтверджені повідомлення Автопро. Для окремої поштової скриньки змініть назву папки у вузлі «Листи Автопро».
2. Імпортуйте `integrations/n8n/avtopro-mail.json`. Додайте облікові дані IMAP для цієї пошти або замініть тригер вузлом поштового сервісу й зіставте його поля `from`, `subject`, `textPlain` і `metadata.message-id`.
3. У «Маркетплейси → Автопро → Підключення та журнал» створіть ключ. У вузлі «Передати в USAparts.top» виберіть Header Auth, назва заголовка `Authorization`, значення `Bearer …` з кабінету.
4. Перевірте розпізнавання на зразку реального повідомлення, після цього опублікуйте сценарій. Якщо номер відсутній, суперечливий або формат теми відрізняється, лист з’являється в журналі для звірки. Після збою доставки відкрийте невдалий запуск n8n та повторіть його, сайт відкине повтор за Message-ID.

Явний номер шукається за написами `замовлення №12345` / `заказ №12345` у темі й тексті. Текст обмежено 5 000 символами. Журнал доступний адміністраторам сайту. n8n зберігає невдалі запуски до 24 годин для повторної доставки.
