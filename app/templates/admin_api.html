Telegram

Для групи chat ID зазвичай починається з -100. Якщо бот не надсилає повідомлення, додайте його в групу і надішліть у групу команду /start або згадайте бота, після чого оновіть сторінку.

Google Merchant

У Google Merchant Center потрібно створити джерело даних типу API, а service account додати до Merchant Center з правом керування товарами. Для Google Merchant API використовується OAuth scope https://www.googleapis.com/auth/content. Якщо бачите помилку GCP project is not registered, спочатку натисніть Зареєструвати GCP project, зачекайте до 5 хвилин і тільки потім перевіряйте доступ.
