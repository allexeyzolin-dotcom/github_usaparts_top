# Місце зберігання на складі

07.11.2026 додано обов’язкове поле **Місце на складі** до ручного додавання та редагування товарів, прийому, товарів у дорозі, ревізії і застосування імпорту. Сервер перевіряє поле перед змінами; перевірки HTML не є єдиним захистом.

Впишіть значення або після 3 символів виберіть із раніше введених. Словник спільний для сайту, ревізії та Android. Він зберігає попередні місця, об’єднує повтори незалежно від регістру й зайвих пробілів. Нове значення можна ввести вручну.

Ревізія використовує список **Усі товари**, віддаючи одну основну картку замість копій кожного складу. Для старих артикулів без master-картки теж віддається один представник. Картки перевіреної наявності залишаються незалежними, зі своїм місцем та кількістю.

## Імпорт

CSV/Excel розпізнає колонку `storage_location`, `storageLocation`, «Місце на складі», «Місце зберігання», «Знаходження на складі», «Полиця» та відповідні назви `location`, `bin`, `shelf`.

Спільне місце у формі завантаження заповнює лише рядки без цієї колонки/значення. Раніше відоме місце наявного складського товару зберігається, якщо у файлі та формі його не замінено. У попередньому перегляді можна уточнити місце кожного рядка. Без заповнення обов’язкових вибраних рядків жодні залишки з імпорту не застосовуються. Зміна лише місця також може бути застосована, навіть коли ціна та кількість не змінилися.

## Сумісність та дані

`storage_location` додано до `parts`, `part_templates`, `receiving_draft_items`, `transit_orders`; `revision_parts` використовує власне поле `location`. Словник — `storage_locations`. Міграція додає колонки з порожнім початковим значенням, не переписує кількості і не вигадує місця старим товарам. Старі записи потрібно уточнити під час наступного ручного збереження.

Фоновий обмін, замовлення та автоматичні зміни залишків не вимагають ручного вводу місця. Редагування картки конкретного складу не переміщує копії інших складів. Словник оновлюється лише при новому/зміненому місці, а повторні вставки в межах однієї транзакції кешуються.

Android **1.4.25 (35)**: такий самий обов’язковий вибір у ревізії, поле з підказками в новій позиції та перед скануванням прийому. Після вибору місця API передає `storageLocation`. Для нового введення потрібно встановити оновлений APK.

Перевірки: **108 ізольованих тестів сайту**, Chromium 1440/390 px, окремий PostgreSQL 16 (міграція зі збереженням залишків, конкуренція словника), `assembleDebug` та `lintDebug`. На робочому складі тестових записів не створювали.
