# Автооновлення залишків із сайту на Автопро

Підготовлено 2 листопада 2026 року для актуального репозиторію `github_usaparts_top`.

## Що додано

У кабінеті: **API → Прайси для Автопро** (`/admin/avtopro-feeds`). Для кожного складу адміністратор може створити й вимкнути окреме посилання на актуальний CSV. Посилання не вимагає сесії адміністратора; доступ обмежується випадковим ключем цього складу. До створення посилань усі прайси недоступні. API Key Автопро не потрібен.

Прайс формується з поточних записів складу при кожному запиті. Валюта USD, базова `price_usd` кожного запису без націнки вітрини. Для бренду й артикула враховуються явно задані експортні поля записи складу. Приватні описи, нотатки ревізій, дані покупців і сторонні склади не експортуються.

Файл UTF-8 із BOM, роздільник `;`, без заголовків. Ціна передається з двома десятковими знаками, артикули не перетворюються на числа. Порядок колонок:

| Поле | Номер |
|---|---|
| Виробник | 1 (A) |
| Код | 2 (B) |
| Ціна | 3 (C) |
| Кількість | 4 (D) |
| Б/В | 5 (E) |
| Реставрація | 6 (F) |
| Опис товару (назва) | 7 (G) |
| Фото | 8 (H) |

Новий товар має порожню позначку Б/В; рядок `0` у базі не перетворюється на позначку вживаного товару. Повторні рядки одного бренду, артикула і стану з однаковою ціною об'єднуються із сумуванням кількості. Різні ціни одного товару або некоректні обов'язкові дані блокують видачу всього файлу з HTTP 503. Запит прайсу не змінює залишки.

## Установлення

Архів містить лише змінені файли коду, шаблони, цю інструкцію та тести. Робочу базу, ключі й cookies не включено. Він підготовлений для актуального репозиторію `github_usaparts_top`; перед установленням потрібно звірити її з поточною серверною версією, щоб зберегти новіші серверні зміни.

Після перенесення змін перебудувати й перезапустити вебконтейнер звичайним способом. Нова таблиця або міграція не потрібна: ключі посилань зберігаються в наявній таблиці `api_settings`. Зміни не вмикають автооновлення в кабінеті Автопро.

## Перше підключення

1. Звірити залишки та базові USD-ціни сайту з відповідним складом Автопро. Автооновлення передає також ціну, оскільки це обов'язкове поле прайсу.
2. На сайті створити посилання для одного складу і завантажити CSV для перевірки. Ключ у посиланні не публікувати; його не потрібно надсилати в чат.
3. Першу перевірку виконати на тестовому складі Автопро: вручну завантажити файл, зіставити колонки за таблицею та перевірити стан Б/В, валюту, кількість, ціни й фото. Ручне оновлення всього складу планувати на 07:00–15:00 за Києвом відповідно до правил Trade Uptime нижче.
4. **Обов'язково перевірити вилучення відсутніх позицій:** товар, що був у попередньому прайсі, але зник із нового, має зніматися з продажу. Довідка описує також об'єднання прайсів, яке для цього завдання не підходить. Семантика такого зняття саме при автооновленні поки не перевірена на Автопро.
5. Після успішної перевірки у робочому акаунті USA SHOP (ID 337792) відкрити потрібний склад → Автооновлення → Через віддалений сервер → Пряме посилання. Додати URL відповідного прайсу та ті самі колонки. Валюта складу — USD. Ідентифікатори складів на сайті й Автопро можуть відрізнятися: прив'язка виконується вибором правильного URL вручну.
6. Перевірити наступне завантаження, а також зміну кількості й зняття проданої позиції. Автопро перевіряє віддалений файл раз на годину, тому це не миттєвий обмін.

## Межі цього способу

- Напрямок: **сайт → Автопро**. Ручні зміни кількості на Автопро не повертаються на сайт і можуть бути замінені наступним прайсом. Це не реалізація раніше обговореної двосторонньої синхронізації.
- Сповіщення про замовлення цим файлом не надходять. Для них потрібен окремий канал; партнерський вебхук не підтверджений як джерело всіх продажів магазину.
- У прайс включаються тільки наявні товари з кількістю понад нуль, як вимагає довідка. Порожній склад повертає HTTP 503. **Останню продану позицію потрібно зняти на Автопро вручну**, доки постачальник не підтвердить і ми не перевіримо обробку порожнього прайсу або інший спосіб зняття всіх товарів.
- Вимкнення ключа зупиняє завантаження, але не видаляє товари на Автопро.

## Trade Uptime

За правилами, перевіреними 2 листопада 2026 року, автоматичне оновлення не погіршує Trade Uptime незалежно від години. Прайс доступний цілодобово: нічної паузи або черги до ранку в реалізації немає.

Ручне оновлення всього складу, зміни активності складів/магазинів та інші перелічені у довідці торгові налаштування слід виконувати у вікні 07:00–15:00 за Києвом для збереження бонусного тарифу. Поза цим вікном вони можуть увімкнути стандартний тариф щонайменше на добу; довідка передбачає також випадки подовження. Час звіряється за Києвом із сезонним переведенням годинника.

Поштучне редагування товару також не впливає на Trade Uptime за чинними правилами. Це стосується й ручного зняття останньої проданої позиції; вимикати весь склад для цього не потрібно.

## Перевірки

Пройдено 33 цільові перевірки: 7 тестів прайсу, 17 тестів пошуку та 9 тестів Google Ads. Повний набір тестів залежить від недоступного локального PostgreSQL; контрольна перевірка попереднього коду також не проходить у цьому середовищі. Перевірено авторизацію адміністратора, CSRF, ізоляцію ключів по складах, відкликання посилань, десяткову ціну, екранування CSV, початкові нулі артикулів, стан Б/В, оновлення кількості, конфліктні/нульові ціни, порожній склад, стабільність файлу й відсутність змін у залишках при завантаженні. Використано одноразову SQLite-базу; робоча база не змінювалася. Сторінку перевірено в браузері на тестових даних.
