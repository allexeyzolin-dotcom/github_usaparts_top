# Пошук, головне фото та місце зберігання

17.11.2026 пошук у вкладці «Запчастини» перевіряє всі склади. Один знайдений склад відкривається автоматично; кілька складів показуються у «Всі товари» з окремими посиланнями. OEM, крос-номер і штрихкод мають пріоритет над текстовими збігами. Товар без позитивного складського залишку відкривається як master-картка для редагування. Ручний вибір складу залишається локальним фільтром (`locate=0`). Відсутній артикул не створюється автоматично.

У master-картці додано окреме збереження фото. Вибір «Фото для імпорту / експорту» визначає також перше фото галереї та обкладинку на сайті в усіх активних складських копіях цього OEM. Додаткові фото кожного складу зберігаються. Завантаження нових фото скидає старий вибір; повторний вибір старого фото дозволений. Фото зберігаються окремо від залишків; перевірена наявність ревізії не змінюється.

Заповнене місце зберігання показується жовтим блоком у картках та замовленнях сайту. API пошуку, перевірки наявності, пакування, видачі й ревізії повертає `storageLocation`; основні картки також отримують `storageLocationLabel` та `storageLocationHighlight`. Для кількох складів кожний запис передає своє місце. Порожні місця не вигадуються.

Telegram додає рядок «📍 Місце на складі» до відповідних повідомлень про товар. Жирне виділення використовує entities з UTF-16 offsets; довільний текст місця не інтерпретується як HTML.

Android 1.4.27 (37) читає місце в пошуку та складських задачах і показує окремий кольоровий блок. Потрібне встановлення оновленого APK. Збірка використовує той самий applicationId і локальний debug signing key.

Перемикання складу в редакторі підтягує комірку та кількість саме обраного складу. Для нової прив’язки місце залишається порожнім до ручного вводу. Автозапис master-картки залишає режим «Всі товари» обраним.

Перевірки: ізольовані регресійні тести сервера та окремі сценарії пошуку, фото й зберігання. PostgreSQL-перевірки пропускаються без окремої QA-БД; 15 storefront-перевірок потребують наповненої зовнішньої тестової БД і не включені в цей запуск. Браузерні перевірки виконувалися на локальних тестових картках; пошук і підсвічування також перевірені на сайті. Android: `assembleDebug`, `lintDebug`.
