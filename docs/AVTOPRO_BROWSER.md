# Avto.pro → USAparts.top

Окремий контейнер запускає Chromium і послідовно перевіряє продажі через Playwright. Для одного джерела й одного одержувача окремий планувальник n8n зайвий. Сервіс працює через HTTPS до USAparts.top і не потребує доступу до PostgreSQL. [Постійний профіль Playwright](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context)

За замовчуванням контейнер стоїть на паузі. Пункт 10.4 умов Avto.pro обмежує використання роботів для збору даних. До пробного зчитування реального кабінету й увімкнення розкладу узгодьте цей спосіб доступу з Avto.pro. [Умови Avto.pro](https://avto.pro/static/regulations/)

## Розгортання в Portainer

1. Оновіть стек сайту кодом із цієї ревізії. Сайт використовує наявні таблиці замовлень і знімків Avto.pro. Нової бази даних або окремої міграції для цієї інтеграції не потрібно.
2. Перевірте, що Nginx Proxy Manager підключений до мережі `proxy_default` і вона вже існує на VPS.
3. Підготуйте файли на VPS. Увійдіть у [«Підключення й імпорт»](https://usaparts.top/admin/marketplaces/avtopro-orders) і використайте чинний ключ імпорту. Якщо потрібен новий ключ, згенеруйте його там. Ротація замінює ключ і для розширення Chrome, якщо воно підключене.

   На сервері виконайте наведені команди з Bash. `htpasswd` постачається з пакетом `apache2-utils` у Debian і Ubuntu. Створіть окремий пароль вебконсолі, відмінний від пароля Avto.pro.

   ```bash
   sudo install -d -m 0700 /opt/usaparts/avtopro
   sudo htpasswd -cB /opt/usaparts/avtopro/console.htpasswd operator
   read -rs -p 'Ключ імпорту USAparts.top: ' avtopro_import_key
   printf '\n'
   printf '%s\n' "$avtopro_import_key" | sudo tee /opt/usaparts/avtopro/site.key >/dev/null
   unset avtopro_import_key
   sudo chown 10001:10001 /opt/usaparts/avtopro/{console.htpasswd,site.key}
   sudo chmod 0400 /opt/usaparts/avtopro/{console.htpasswd,site.key}
   ```

4. У Portainer для Docker Standalone створіть один стек `usaparts-avtopro` через **Stacks → Add stack → Repository**. Вкажіть Git-репозиторій сайту, ревізію з цими файлами й Compose path `docker-compose.avtopro.yml`. Стек збирає свій образ із репозиторію. Шляхи до файлів секретів абсолютні та стосуються VPS із Docker Engine.
5. У Nginx Proxy Manager створіть Proxy Host на окремому піддомені. Forward Scheme `http`, Forward Hostname `avtopro-browser`, Forward Port `8080`. Увімкніть **Websockets Support**, сертифікат TLS та **Force SSL**. За можливості обмежте піддомен IP-адресами операторів або приватною мережею. Nginx усередині контейнера перевіряє Basic Auth для консолі й робочого столу, а для WebSocket також вимагає HTTPS Origin того самого хоста. Порти VNC, WebSocket і керування контейнером залишаються на loopback контейнера.
6. Переконайтеся, що контейнер `healthy`, а захищена консоль відкривається лише після введення окремого пароля. На Ubuntu з обмеженими користувацькими просторами імен Chromium може не стартувати. Якщо в логах є `No usable sandbox` / `Operation not permitted`, перевірте політику user namespaces на Docker-хості та його AppArmor-профіль. Chromium має запускатися у власній пісочниці.

Файли секретів монтуються тільки для читання. При заміні файлу через перейменування перестворіть контейнер, щоб Docker перепідключив файл. Профіль і режим зберігаються в томі `browser-profile`. Звичайний перезапуск його зберігає. Профіль містить сесію продавця, тому ставтеся до нього як до секрету.

Ліміт контейнера 0,85 CPU та 1200 МБ RAM, до 256 процесів, 256 МБ спільної пам’яті. Docker автоматично ротує 3 файли логів по 5 МБ. Профіль seccomp походить із Playwright v1.64.1. Додано виклик chroot для пісочниці Chromium й вилучено виклики io_uring. [Профіль Playwright](https://github.com/microsoft/playwright/blob/v1.64.1/utils/docker/seccomp_profile.json) · [Документація seccomp](https://docs.docker.com/engine/security/seccomp/)

## Вхід і контрольна перевірка

1. Натисніть **Відкрити Avto.pro для ручного входу** й **Відкрити захищений браузер**. У браузері введіть пошту й пароль і, якщо з’явиться запит, пройдіть CAPTCHA або підтвердження вручну. Перейдіть у **Продаж → Всі**. Закрийте вкладку з віддаленим робочим столом, щоб звільнити керування браузером.
2. Після дозволу Avto.pro натисніть **Перевірити зчитування без передачі**. Звірте, скільки карток прочитано. Режим перевірки не надсилає даних до USAparts.top. Якщо список не розпізнано, перевірте активну вкладку продажів.
3. Перезапустіть контейнер без видалення тому. Повторіть пробне зчитування й переконайтеся, що чинна сесія відкривається без повторного входу. Якщо у браузері збереглася лише сесійна cookie й платформа її закінчила, увійдіть ще раз звичайним способом.
4. Першу перевірку запису виконайте зі стендом USAparts.top через `USAPARTS_ORIGIN`. Використовуйте ключ саме цього стенда. Звірте одну картку з її номером, артикулами, кількістю, сумою, статусом і доставкою. Повторна перевірка має залишити одну картку. У відкритому замовленні з ТТН Нової пошти звірте номер у полі ТТН та у відомостях Avto.pro. Для наявного скасованого замовлення без відправки звірте перехід в «Історію». Відправлене замовлення зі скасуванням відображається для звірки повернення.
5. Після успішної перевірки на реальному кабінеті увімкніть синхронізацію у потрібному середовищі. Після втрати сесії вебконсоль показує стан, а кабінет сайту отримує сповіщення за наявності зв’язку. Повторний вхід і відновлення розкладу запускаються вручну. Стан сесії й результати перевірок також видно у захищеному `/status`.

## Що обробляється

- Сервіс шукає нові продажі на першій сторінці списку продавця. Картку вперше відкриває за статусом «Нове», «Замовлення формується» або «Очікує на підтвердження». Статус перевіряється повторно в самій картці перед створенням.
- Уже імпортовані відкриті замовлення перевіряються за номерами, навіть якщо зникли зі списку. Для них сервіс передає тільки статус і присвоєну ТТН. Скасування підтверджується за статусом картки. До відправлення воно архівує картку і звільняє наявний резерв один раз. Після відправлення потрібна звірка повернення.
- ТТН зчитується з явно підписаного поля або системного запису Avto.pro. Однозначний номер Нової пошти заповнює порожнє поле ТТН у картці USAparts.top. Якщо номер відрізняється від збереженого в USAparts.top, обидва номери доступні для звірки. Номери інших перевізників видно в даних Avto.pro.
- Автоматичне читання відкриває сторінки й читає видимі поля. У режимі опитування браузер блокує методи запису й WebSocket сторінки. Ручний вхід відбувається на окремій вкладці й не потребує зберігання пароля в Compose.
- `AVTOPRO_INTERVAL_SECONDS` задає паузу між завершенням одного циклу й початком наступного. Типово 300, діапазон 60–86400. `AVTOPRO_BATCH_SIZE` задає максимум нових карток та окремо максимум відстежуваних існуючих карток на цикл. Типово 10 кожного типу, діапазон 1–20. Цикли не накладаються, між картками є пауза 1 секунда.
- Щоб зупинити опитування, натисніть **Призупинити**. У Portainer можна зупинити стек, зберігши том і профіль.

Тести Chromium використовують локально підмінені HTML-сторінки й тестову сесію. Структуру системного запису з ТТН перевірено в реальній картці продавця. Розклад слід увімкнути після перевірки запису й повторного входу в серверному браузері.
